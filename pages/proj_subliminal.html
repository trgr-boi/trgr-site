# https://subliminal.trgrboi.be

This is Subliminal.OS.
It is a terminal-like site I made. This was originally for a assignment when I was still studying graphic design, but got reworked later to have better JavaScript when I learned it in my first year in Applied Computer Science.

I started to hide some stuff in there. This is not finished, and will likeley never be finished. My goal was to make something like Bandit by Over The Wire. Hiding things that needs to be found to make progress. Back when I made this, I was really into ARGs and wanted to make one myself. This was at the same time I became really fascinated by the terminal and CLI interfaces (still am tbh) and wanted to make it as beginner-friendly as possible.

I might finish this one day, but won't make any promises! For now, enjoy what is there!
